## Justified interpretation calls for root

1. **Edge-follow vs Sidelight-made contact.** Avoidance always leaves an 8 pt gap, so every window the details panel pushes "touches" it at +8. A literal follow-first rule would pull a window that was clear of the side panel (e.g. x=250 before, pushed to 368) out to the side panel's edge on close, contradicting "moves nothing outward" and "goes back if unchanged". I apply follow-first to changed/new windows and to unchanged windows that were already snapped to the returning edge (Sol's priority test and R4's example both pass by reasoning); other unchanged windows restore. Please confirm.
2. **main→main resize/move now restores via the ledger** (unchanged windows start from their pre-panel frame). It replaces the one-way 600 ms sweep and is consistent with show/hide restoration, but it is new behaviour for width changes.
3. **401/403 are terminal for manual refresh too** until the key is saved again (root brief). A 403 caused by a since-fixed permission needs a re-save.
4. **Credits previews never show real money**, even for an already-added widget in the builder. Models previews show the live public catalogue when cached.
