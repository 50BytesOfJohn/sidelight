## First release

Sidelight is a native side panel or top/bottom bar for Apple Silicon Macs running macOS 26 or newer.

- Keep a clock, Codex usage, calendar events, now playing, agent activity and system stats in view.
- Customize the panel's position, size, widgets, backgrounds and appearance, including settings for each display.
- Keep other windows clear of the panel with automatic window avoidance.
- Show or hide the panel with a global keyboard shortcut.
- Receive signed updates from GitHub through the app's update settings and menu bar.

The installer and app are Developer ID signed and notarized by Apple. Drag Sidelight into Applications to install.
macOS asks for Accessibility access for window management; Calendar access is optional. Some widgets use optional
command-line tools; see the README for setup details.
